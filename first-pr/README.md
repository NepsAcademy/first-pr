# first-pr
Repository for Neps Academy Git course students to make their first Pull Request 🚀

## How to contribute

1. Fork this repository and create a branch.
2. Add **a single line** to the end of [`Contributors.md`](Contributors.md) using this format:

   ```
   - [Your Full Name](https://github.com/your-username)
   ```

3. Open a pull request to `main`.

A bot checks every pull request and merges it automatically when everything is right. If something needs fixing, it leaves a comment explaining what to change. Just push a new commit to the same branch, there's no need to open another pull request. Merge conflicts with other contributors are handled by the bot.

The bot checks that:

- only `Contributors.md` was changed;
- exactly one line was added and no existing lines were changed;
- the line follows the format above and links to your own GitHub profile;
- your profile is not on the list yet.
